Send one complete LEGO Wireless Protocol packet as hexadecimal bytes, including its length byte and hub ID.

Only send packets you understand. Output commands may activate motors or other connected devices. This sender accepts packets up to 20 bytes; it does not split larger packets.

JavaScript console · Mario API

Write ordinary JavaScript: variables, functions, arrays, loops, objects, classes, promises, async/await, try/catch and console logging work. The isolated runner exposes JavaScript built-ins plus the mario hardware library; it does not expose the page DOM.

Ready. Connect Mario before using Bluetooth commands.

Script output will appear here.

Library: mario.log(text), mario.delay(ms), mario.subscribe(port, mode, delta?), mario.unsubscribe(port, mode), mario.readPort(port), mario.requestPortInfo(port, infoType), mario.requestPortModeInfo(port, mode, infoType), mario.requestHubProperty(property), mario.getHubInfo(), mario.requestBatteryLevel(), mario.requestFirmwareVersion(), mario.requestHardwareVersion(), mario.requestRSSI(), mario.setVolume(0..100), mario.requestButtonState(), mario.setBusyIndicator(enabled), mario.enableBatteryUpdates(), mario.disableBatteryUpdates(), mario.sendHex(packet), mario.disconnect().

Scripts can send Bluetooth commands to the connected hub. The volume API uses Mario's separately verified extension. mario.displaytext(text) remains unavailable: LEGO's published protocol does not document a custom-text display command for Mario.

Important: the published protocol does not define a remote restart command. After 10 seconds this sends Switch Off (0x01), so you must press Mario's power button to turn it back on. This does not install firmware; use the official LEGO app for actual updates.
