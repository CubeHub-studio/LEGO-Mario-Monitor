Send data · Bluetooth

Send one complete LEGO Wireless Protocol packet as hexadecimal bytes, including its length byte and hub ID.

Connect Mario before sending.

Only send packets you understand. Output commands may activate motors or other connected devices. This sender accepts packets up to 20 bytes; it does not split larger packets.

JavaScript console · Mario API

Write JavaScript using the built-in mario library. Scripts run in an isolated browser frame and can only use the documented commands below.

Ready. Connect Mario before using Bluetooth commands.

Script output will appear here.

Library: mario.log(text), mario.delay(ms), mario.subscribe(port, mode), mario.requestPortInfo(port, infoType), mario.sendHex(packet), mario.displaytext(text) (not implemented: display protocol unknown).

Only run scripts you wrote or understand. Scripts can send Bluetooth commands to the connected hub. displaytext() is included as a placeholder, but it will report that custom screen writing is not yet supported rather than pretending to change Mario's display.

Packets will appear here after connecting.
Camera limitation: LEGO Mario does not expose a camera image stream. The “Sensor view” is an honest visualization of sensor packets, not a live video feed. Unknown values are shown as raw bytes rather than guessed.

Runs locally in your browser. No account, API key, server, or paid service. Bluetooth requires a supported browser and a secure page (HTTPS or localhost).
